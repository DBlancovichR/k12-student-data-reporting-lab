# FERPA-Aware Data Handling

## Purpose

This document describes privacy-aware handling practices for student data in education systems.

## Core Practices

- Use synthetic data for testing and portfolio work.
- Do not upload real student data to public repositories.
- Limit access to student records based on job responsibility.
- Share only the minimum data required for the task.
- Avoid sending sensitive student information through unsecured channels.
- Store exports only in approved locations.
- Remove local copies when they are no longer needed.
- Document who requested data, what was shared, and why.

## Portfolio Note

This project uses synthetic records only. Names, student IDs, program records, transcript data, attendance data, and discipline records were created for demonstration purposes.

## Example Access Controls

| Role | Appropriate Access |
|---|---|
| Registrar | Enrollment, withdrawal, transcript records |
| Counselor | Senior status, transcript review, program data |
| Administrator | Reporting summaries and discipline data |
| Teacher | Limited class/student information |
| IT/Data Specialist | System support and reporting extracts as assigned |
