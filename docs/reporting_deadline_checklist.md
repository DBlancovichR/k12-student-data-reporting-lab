# Reporting Deadline Checklist

## Purpose

This checklist supports recurring education data reporting preparation.

## Pre-Reporting Checklist

- Confirm source data files are received.
- Confirm student file is current.
- Confirm enrollment file is current.
- Review active enrollment counts by grade.
- Review inactive enrollments for missing exit codes.
- Review senior graduation status.
- Review program participation counts.
- Review discipline summary.
- Review attendance summary.
- Generate exception report.
- Resolve open data exceptions.
- Save final reporting outputs.
- Document date, owner, and review notes.

## Reporting Output Files

- `reports/enrollment_by_grade_report.csv`
- `reports/data_quality_exception_report.csv`
- `reports/senior_exit_status_report.csv`
- `reports/program_participation_report.csv`
- `reports/crdc_style_discipline_summary.csv`
