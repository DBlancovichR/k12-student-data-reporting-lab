# Staff Training Guide

## Purpose

This guide outlines how selected staff should review and correct common student data issues.

## Training Topics

1. How to identify duplicate student records.
2. How to review inactive students with missing exit codes.
3. How to confirm senior graduation status.
4. How to review program participation status.
5. How to document a data correction.
6. How to escalate unresolved reporting issues.

## Staff Workflow

1. Receive data exception report.
2. Locate assigned exception.
3. Review the source record.
4. Confirm correct value using approved source.
5. Update the system or request correction.
6. Add notes to the ticket.
7. Mark exception as resolved after validation.

## Example Correction

Issue:

- Student 1006 is inactive and has an exit date, but no exit code.

Correction:

- Registrar confirms withdrawal reason.
- Exit code is added to the enrollment record.
- Validation query is re-run.
- Ticket is closed after exception no longer appears.

## Escalation

Escalate to IT, SIS vendor support, or administration when:

- The system rejects a valid update.
- Required fields are unavailable.
- Vendor import/export fails.
- Data discrepancy affects mandated reporting.
